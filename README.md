# 3D Autonomous Excavator Digital Twin

## Algoryx Internship – Task 4

This project is an original 3D Autonomous Excavator model created as part of the Algoryx Internship Task 4 – Become an Algoryx Community Creator.

## Project Overview

The project focuses on creating a detailed 3D digital asset of an autonomous excavator using Blender. The model includes the excavator body, cabin, hydraulic arms, tracks, bucket, control elements, materials, lighting, and a professional rendered presentation.

The final asset was exported in GLB format for use in digital twin and 3D applications.

## Features

- Original 3D autonomous excavator model
- Detailed excavator body and cabin
- Hydraulic arm and bucket
- Track-based movement system
- Custom materials and colors
- Professional lighting and rendering
- Optimized GLB export
- Suitable for digital twin visualization

## Technologies Used

- Blender 5.2 LTS
- Blender EEVEE
- GLB / glTF 2.0
- 3D Modeling
- Digital Twin Visualization

## Files Included

- `Autonomous_Excavator_Professional.blend` – Blender source file
