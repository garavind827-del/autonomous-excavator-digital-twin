TASK 4 – AUTONOMOUS EXCAVATOR DIGITAL TWIN

Project Title:
Autonomous Excavator Digital Twin

Description:
A 3D model of an autonomous excavator created using Blender.
The model represents the major components of an excavator, including
crawler tracks, chassis, cabin, boom, arm, hydraulic cylinders and bucket.

Tools Used:
- Blender 5.2 LTS
- Blender Python scripting

Main Features:
- Excavator crawler tracks
- Cabin with glass panels
- Hydraulic cylinders
- Boom and arm assembly
- Excavator bucket with teeth
- Autonomous warning/sensor light
- Construction-style materials and lighting
- Camera setup and rendered presentation

Project Files:
- Autonomous_Excavator_Professional.blend
- Autonomous_Excavator_Professional_Render.png

Purpose:
This project demonstrates basic 3D modelling and visualization of an
autonomous construction machine as part of the internship Task 4.
